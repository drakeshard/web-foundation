# @drakeshard/testing

Testing support for Drakeshard Web Foundation consumers.

## Install

```sh
pnpm add -D @drakeshard/testing
```

## Public entry points

- `@drakeshard/testing/clock` — `ManualClock` for explicit test-controlled time.

The package intentionally remains small and does not provide a generic simulation framework.
